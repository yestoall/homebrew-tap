# yestoall/tap

Homebrew casks for apps by [@yestoall](https://yestoall.com).

## TICS

Your Mac sounds like a mechanical keyboard as you type, and like a mouse as you click.
[More about TICS](https://github.com/yestoall/tics).

```bash
brew install --cask yestoall/tap/tics
```

To update it, run `brew upgrade --cask tics`. To remove it, run `brew uninstall --cask tics`, or
`brew uninstall --zap --cask tics` to delete its settings too.
